# IELTS AI Master

An advanced AI-powered IELTS preparation app built with Flutter & Firebase. The app helps students improve their Listening, Reading, Writing, and Speaking skills with modern UI, AI-based evaluation, real-time progress tracking, and smart study tools.

---

## 🚀 Features

### 🎧 Listening Module

* AI-generated listening tests
* Audio playback with transcript support
* Multiple choice questions
* Automatic score & band calculation
* Result history saved in Firebase

### 📖 Reading Module

* IELTS-style reading passages
* MCQs, True/False, and Fill in the blanks
* Instant answer checking
* Band score calculation

### ✍️ Writing Module

* AI Writing evaluation
* Task 1 & Task 2 support
* Grammar and vocabulary feedback
* Estimated IELTS band score
* Writing history tracking

### 🎤 Speaking Module

* AI-generated speaking topics
* Part 1, Part 2, and Part 3 questions
* Voice recording support
* AI-based speaking feedback
* Fluency and pronunciation analysis

### 🤖 AI Features

* Gemini AI integration
* Smart IELTS assistant
* Personalized study suggestions
* AI-generated practice tests

### 🔐 Authentication

* Firebase Email & Password Login
* Google Sign-In
* Secure user data management

### 📊 Progress Tracking

* User performance analytics
* Band score history
* Daily learning progress
* Firebase cloud storage

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Muhammad-Rashid-172002/IELTS-AI-Master-Privacy-policy-.git
```

### 2️⃣ Open Project

```bash
cd ielts-ai-master
```

### 3️⃣ Install Packages

```bash
flutter pub get
```

### 4️⃣ Run App

```bash
flutter run
```

---

## 🔥 Firebase Setup

1. Create Firebase Project
2. Enable Authentication
3. Enable Firestore Database
4. Add Android & iOS Apps
5. Download configuration files:

### Android

* `google-services.json`

### iOS

* `GoogleService-Info.plist`
